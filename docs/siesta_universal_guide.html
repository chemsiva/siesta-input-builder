Abstract

The SIESTA Input Builder is an open-source, client-side web application designed to eliminate the steep learning curve, manual formatting errors, and scattered keyword documentation of the SIESTA density functional theory (DFT) software suite. Providing an intuitive graphical interface equivalent to BURAI or pw.gui for Quantum ESPRESSO, it covers the complete operational lifecycle: from initial crystal import (CIF/POSCAR) to advanced constraints, reaction path CI-NEB interpolation, vibrational phonon matrices, real-space surface work functions, and execution time accounting. This handbook serves as the exhaustive operational reference, detailing every screen, button, drawer, and hidden shortcut across the 13 modular sections.

Application Architecture & Global Workflow

Zero-Backend Security & Privacy Architecture

Unlike cloud DFT portals that require uploading sensitive structure files to third-party remote servers, the SIESTA Input Builder runs 100% inside your local browser:

  • No Server Computing: Built with React 19, Vite, and Zustand. All CIF parsing, VASP coordinate transformations, 3D WebGL rendering, and FDF generation take place in your browser’s V8 JavaScript engine.

  • Confidentiality of Novel Materials: Proprietary atomic coordinates, unreleased battery/catalyst crystal structures, and unpublished coordinates never cross the network. You can disconnect your internet entirely after opening the site, and the application remains fully functional.

  • Zero Installation Friction: Requires no Python environments, no compilation of GUI toolkits (Tkinter/Qt), and no local server daemons. Works across Linux, macOS, Windows, and tablet browsers.

The Three-Panel Layout

The application interface is divided into three functional areas:

  1. Top Toolbar (Header): Global project controls, one-click template presets, convergence sweep package generators, CIF/FDF import, validation engine, export actions, and Dark/Light theme switching.

  2. Left Navigation Sidebar: The master index providing rapid switching between all 13 specialized calculation sections, accompanied by a dynamic real-time validation warning badge.

  3. Main Workspace Pane: The active form interface with contextual tooltips, parameter units, interactive data grids, 3D visualizers, and analysis studios.

  4. Right-Hand Live FDF Preview Pane: A persistent 320px wide code drawer that regenerates the exact, formatted, production-ready .fdf file on every single keystroke.

Dark and Light Mode Switching

Located in the upper right of the Toolbar:

  • Dark Mode (Default): Tailored for long computing sessions and night research. High-contrast slate backgrounds (#0f1117) with vibrant syntax accents.

  • Light Mode: Crisp, publication-white canvas (#ffffff) with deep slate typography (#0f172a). Ideal for capturing clean figures, creating presentation slides, and working in bright daylight.

  • State Persistence: The selected theme is stored in browser localStorage under siesta_theme, restoring your preferred appearance across browser refreshes.

The Global Toolbar & Top Navigation

Pre-Configured Calculation Templates (Templates ▾)

The Templates dropdown allows instant population of standard scientific workflows in a single click:

  • Bulk SCF (Single-Point): Sets up high-precision total energy calculation on periodic crystals. Configures MaxSCFIterations 100, DM.Tolerance 1.0d-4, MeshCutoff 300 Ry, and Monkhorst-Pack kk-grid.

  • Geometry Relaxation (CG): Configures atomic position minimization via Conjugate Gradient (MD.TypeOfRun CG), sets force tolerance to 0.04 eV/Å, and requests force output (WriteForces true).

  • Variable-Cell Relaxation: Optimizes both atomic positions and cell vectors (MD.VariableCell true), maintaining stress tolerance at 1.0 GPa.

  • Band Structure Calculation: Configures SCF convergence followed by dispersion tracking along high-symmetry kk-lines (BandLinesScale ReciprocalLatticeVectors).

  • Slab / Surface Calculation: Automatically expands unit cell along zz, enables Slab.DipoleCorrection true, enforces kz=1k_z = 1, and requests electrostatic potential output (SaveElectrostaticPotential true).

  • Density of States (DOS + PDOS): Configures orbital-resolved projected DOS energy window (EF -10.0 10.0 0.1 1000 eV) and dense kk-mesh.

Automated Convergence Suite Generator (Convergence Suite ▾)

Achieving publication-grade DFT results requires proving that your energy and lattice parameters are converged with respect to numerical cutoffs. The toolbar provides automated zip package generators:

  1. MeshCutoff Sweep (MeshCutoff Sweep (.zip)):

    • Generates a complete series of individual FDF files stepping from 150 Ry to 500 Ry (150, 200, 250, 300, 350, 400, 450, 500 Ry).

    • Includes an automated parallel bash runner script (run_mesh.sh) with SLURM/MPI execution commands.

    • Includes a Python script (plot_mesh_convergence.py) using matplotlib to extract total energies from stdout and plot the convergence plateau (|ΔE|<1 meV/atom|\Delta E| < 1\text{ meV/atom}).

  2. K-Grid Sweep (K-Grid Sweep (.zip)):

    • Generates a series of kk-mesh densities (4×4×4,6×6×6,8×8×8,10×10×10,12×12×124\times4\times4, 6\times6\times6, 8\times8\times8, 10\times10\times10, 12\times12\times12).

    • Automatically respects 2D slab geometry if active (Nx×Ny×1N_x \times N_y \times 1).

    • Bundles automated runner and convergence plotting scripts.

File Import Engines: CIF and FDF

  • Import CIF: Ingests raw .cif files from databases (Materials Project, ICSD, COD, AFLOW, VESTA). The client-side CIF parser extracts:

    • Lattice parameters (a,b,c,α,β,γa, b, c, \alpha, \beta, \gamma) and converts them to Cartesian lattice vectors.

    • Atomic coordinates and fractional space-group symmetry expansions.

    • Chemical element symbols and automatically assigns atomic numbers ZZ.

    • Populates Section 1⃝, 2⃝, and 3⃝ simultaneously.

  • Load .fdf: Round-trip loader. Ingests any legacy or modern SIESTA input file, parses keywords and blocks, and repopulates every form control across all sections.

Interactive Validation Engine (Validate)

Clicking **Validate** runs a comprehensive consistency check against official SIESTA rules:

  • Flags empty or invalid SystemLabel identifiers.

  • Verifies that species indices in AtomicCoordinatesAndAtomicSpecies match entries in ChemicalSpeciesLabel.

  • Warns if MD.VariableCell true is active on a surface slab with unconstrained cc-axis.

  • Flags non-physical cutoffs (e.g., MeshCutoff < 100 Ry).

  • Highlights errors with a red badge in the sidebar and lists exact remedy steps.

Export Mechanisms: Plain FDF vs. Complete Cluster Package

  • Download .fdf: Downloads the single active .fdf input file.

  • Download Package: The recommended export for HPC clusters. Downloads a ready-to-run .zip package containing:

    1. SystemLabel.fdf: The complete calculation input.

    2. run_siesta.sh: Production bash submission script configured with your specified pseudopotential directory:

      #!/bin/bash
# Auto-generated by SIESTA Input Builder
export SIESTA_PS_PATH="/scratch/user/pseudos"
export SIESTA_PP_PATH="/scratch/user/pseudos"
mpirun -np 4 siesta < SystemLabel.fdf | tee SystemLabel.out

    3. README_RUN.txt: Execution instructions, MPI core recommendations, and post-processing commands.

Section-by-Section Walkthrough & Hidden Details

Section 1⃝ System: Basic Identifiers & Auto-Detection

  • SystemLabel: The core naming string prefixed to all calculation output files (e.g. SystemLabel.out, .DM, .bands, .ANI, .VH, .times). Avoid spaces or special characters.

  • SystemName: A descriptive title for human readability.

  • Hidden Power Detail (SIESTA 5 Auto-Detection): In legacy SIESTA 4.x, NumberOfAtoms and NumberOfSpecies were mandatory. In modern SIESTA 5.x, these values are automatically counted by the code from the coordinate and species blocks. If you leave these fields blank in the GUI, the builder cleanly omits them from the FDF, preventing count mismatch errors when adding or removing atoms!

Section 2⃝ Structure: Lattice, Slabs & 3D Crystal Viewer

Coordinate Formats and Units

The AtomicCoordinatesFormat selector toggles how atomic positions are interpreted:

  • Fractional: Dimensionless values 0.0≤u,v,w<1.00.0 \le u, v, w < 1.0 relative to unit cell basis vectors.

  • NotScaledCartesianAng: Direct Cartesian positions (x,y,z)(x, y, z) in Ångströms.

Slab Cleavage & Vacuum Engineering

Located in the dedicated ** Slab & Vacuum Tools** card:

  • Add Vacuum Along Z: Specify desired vacuum thickness (e.g. 15.0 Å or 20.0 Å). Clicking **Add Vacuum** automatically expands the a3/ca_3 / c lattice vector and turns on Slab.DipoleCorrection true in Section 4⃝.

  • Center Slab in Cell: Shifts atomic zz-coordinates so that vacuum is symmetrically distributed above and below the atomic layers, preventing boundary clipping.

  • Supercell Multiplier: Enter Nx,Ny,NzN_x, N_y, N_z (e.g. 2×2×12 \times 2 \times 1) to replicate unit cell atoms into an expanded supercell for defect or adsorption modeling.

Atomic Coordinates Table: Hidden Batch Clipboard Paste

  • Adding/removing atoms row by row is supported via **+ Add Atom** and the red **** button.

  • Hidden Power Detail (Batch Paste): You do not need to type coordinates one by one! If you copy tabular text from Excel, VESTA, or a text file formatted as:

    0.000000 0.000000 0.000000 1 Pb
0.500000 0.500000 0.000000 2 I

    simply click on any table cell and press Ctrl+V (or Cmd+V). The builder automatically parses the rows, expands the table, and populates x,y,zx, y, z, species indices, and labels instantly!

Interactive 3D Crystal Visualizer (WebGL & Canvas 2D)

By default, the 3D viewer is set to **OFF** to guarantee zero lag when opening the page on low-power devices. Clicking **Turn ON 3D Viewer** activates the interactive viewport:

  • Interactive Orbit Controls: Left-click drag to rotate; right-click drag to pan; mouse scroll to zoom in/out.

  • Perspective vs Orthographic: Switch between real perspective and orthogonal projections.

  • Axes & Unit Cell: Toggle RGB Cartesian axes (a1=red,a2=green,a3=bluea_1 = \text{red}, a_2 = \text{green}, a_3 = \text{blue}) and unit cell bounding box.

  • Camera Snapping: One-click projection buttons to snap directly to Top view (XY), Side view (XZ), or Front view (YZ).

  • High-Resolution Snapshot: Click **Screenshot** to capture a publication-grade transparent PNG image of your crystal structure directly from the canvas.

  • Dual-Engine Fallback: If running inside a virtual machine or browser with WebGL disabled, the viewer automatically switches to an optimized HTML5 Canvas 2D engine.

Section 3⃝ Species & Basis: Pseudopotential Directory Scanner

The Remote Server Path Embedding Problem

A frequent frustration in SIESTA calculations: you build an input on your laptop, copy the .fdf to a remote supercomputer cluster, and the job immediately crashes with:

Could not find pseudopotential file: Pb.psf

In SIESTA, %block ChemicalSpeciesLabel supports an optional fourth column specifying the absolute filesystem path to the pseudopotential file:

%block ChemicalSpeciesLabel
 1 82 Pb /scratch/SIVAKUMAR/pseudos/Pb.psf
 2 53 I /scratch/SIVAKUMAR/pseudos/I.psf
%endblock ChemicalSpeciesLabel

When specified, SIESTA reads the pseudopotentials directly from that directory regardless of where you submit the job from!

Folder Scanner & Real-Time Matcher

In **Step 1**, enter the absolute path where your pseudopotentials reside on the cluster (e.g., /scratch/user/pseudos). In **Step 2**, click **Scan Folder** and choose the local folder on your computer:

  • The browser uses HTML5 ‘webkitdirectory‘ to scan filenames locally without uploading file content.

  • Click **Auto-Assign All**: The builder matches elements (e.g. symbol ‘Pb‘ matches ‘Pb.psf‘, ‘Pb_pbe.psf‘, or ‘Pb.psml‘).

  • Status Badges: The table displays green **‘Found‘** badges for confirmed files and amber **‘Missing‘** badges for missing pseudopotentials.

Basis Set Customization

  • PAO.BasisSize: Select DZP for production calculations; SZ for quick initial geometry screening.

  • PAO.EnergyShift: Slider and text box with unit conversion (meV, Ry, eV). Default is 100 meV.

  • Soft Confinement Drawer: Toggle PAO.SoftDefault true to soften orbital second derivatives at cutoff boundaries, suppressing eggbox oscillations.

Section 4⃝ DFT / XC: Exchange-Correlation, vdW & DFT+U

  • XC Functional & Authors: Select functional type (GGA, LDA, VDW) and author parameterization (PBE, PBEsol, CA, revPBE).

  • MeshCutoff: Energy cutoff governing real-space grid fineness. Standard values: 250–350 Ry for semiconductors; 350–450 Ry for oxides and transition metals.

  • Grimme DFT-D3 Dispersion: Toggle DFTD3 true with choice of zero damping or Becke-Johnson (BJ) damping.

  • Spin Mode: Toggle between unpolarized, polarized (collinear), non-collinear, and spin-orbit.

  • Magnetic State Assistant: Click presets for Ferromagnetic (all spins aligned), Antiferromagnetic (alternating ±S\pm S), or Non-collinear spiral spins to auto-format the %block DM.InitSpin block.

  • DFT+U Assistant (%block DFTU.Proj): For transition metals (Ni,Co,Fe,TiNi, Co, Fe, Ti) or rare earths (CeCe) where standard DFT fails due to self-interaction errors:

    • Enable DFT+U and select species.

    • Specify orbital shell (dd or ff), Hubbard on-site Coulomb UU (eV), and Hund’s exchange JJ (eV).

    • Automatically formats the formal SIESTA %block DFTU.Proj block.

Section 5⃝ SCF Control: Convergence & Mixing

  • MaxSCFIterations: Maximum iteration limit (typically 100–150).

  • DM.Tolerance: Convergence density matrix threshold (typically 1.0d-4 to 1.0d-5).

  • DM.MixingWeight: Linear mixing parameter. Hidden Troubleshooting Tip: If your calculation diverges or oscillates with wild energy swings, reduce mixing weight from 0.25 down to 0.05 or 0.08.

  • DM.NumberPulay: Pulay DIIS history depth (typically 6 to 8).

  • ElectronicTemperature: Fermi-Dirac smearing width (typically 25 meV for metals; 0 meV for insulators).

  • DM.UseSaveDM: Toggle to true when restarting a calculation from an existing SystemLabel.DM density matrix file.

Section 6⃝ K-Points: Reciprocal Mesh & High-Symmetry Band Path

Reciprocal Mesh Setup

Configure Monkhorst-Pack grid divisions (Nx×Ny×NzN_x \times N_y \times N_z) and displacement shifts (0.50.5 for off-Γ\Gamma, 0.00.0 for Γ\Gamma-centered). Dimensionality Protection: If modeling a 2D slab or surface, the builder displays a guidance note reminding you to set kz=1k_z = 1.

Automated High-Symmetry Band Path Generator

Located in the **High-Symmetry Band Path Generator** card:

  • Click **Auto-Detect Lattice Path**: The builder inspects your lattice vectors and identifies the Bravais lattice type (Cubic, FCC, BCC, Tetragonal, Hexagonal, Rhombohedral, Slabs).

  • It pre-populates standard crystallography paths (e.g. Γ→X→W→L→Γ\Gamma \to X \to W \to L \to \Gamma for FCC crystals; Γ→M→K→Γ\Gamma \to M \to K \to \Gamma for hexagonal/2D systems).

  • Customize division points per line segment and click **Apply to BandLines**.

  • Fatbands Export: Toggle WFS.Write.For.Bands true to output wavefunctions into SystemLabel.fullBZ.WFSX for orbital-projected band structure analysis.

Section 7⃝ Bands & DOS / PDOS: Electronic Structure

  • Projected DOS (%block ProjectedDensityOfStates): Configure energy window (EminE_{\text{min}} to EmaxE_{\text{max}}), Gaussian peak broadening width (σ\sigma), number of points, and energy units. Toggle EF to align energy relative to the Fermi level.

  • Custom PDOS k-grid: Toggle PDOS.kgrid.MonkhorstPack to use a denser kk-point mesh for the DOS calculation than was used for the self-consistent SCF charge density.

  • Local Density of States (LDOS): Spatial energy window slice (%block LocalDensityOfStates).

  • WriteEigenvalues: Toggle to write all Kohn-Sham eigenvalues to SystemLabel.EIG.

Section 8⃝ Output Flags & Results Viewer

This section contains two distinct workspaces selected via top tab pills:

Tab 1: FDF Output Flags

Configure which files SIESTA produces:

  • Trajectories: WriteMDXmol true (⟹\implies .ANI for VMD/JMol/OVITO), WriteMDhistory true (⟹\implies .MDE thermodynamic record), WriteCoorXmol true (⟹\implies .xyz).

  • Real-Space Grids: SaveRho (charge density), SaveDeltaRho (charge difference), SaveElectrostaticPotential (⟹\implies .VH for work functions), SaveTotalPotential (.VT), SaveHS (.HSX matrices).

  • Section 6.29 Accounting Flags: AllocReportLevel (0 to 4 in .alloc), TimerReportThreshold, UseParallelTimer, MaxWalltime queue limit, and MaxWalltime.Slack.

Tab 2: Results Analysis & Viewer Workspace

Drag and drop (or upload) calculation output files:

  • Log Inspector (.out): Extracts final total energy, Fermi energy, mesh cutoff used, cell volume, forces, and normal completion status.

  • Convergence Charts (.MDE / .out): Interactive SVG curves showing total energy convergence across geometry steps and SCF density matrix residual history.

  • 3D Trajectory Player (.ANI): Play molecular dynamics or relaxation movies. Scrub through frames with a slider, control playback speed, step forward/backward, and toggle between WebGL and Canvas 2D rendering.

  • Electronic Band Structure Plotter (.bands): Renders E(𝐤)E(\mathbf{k}) dispersion with adjustable Fermi level offset, high-symmetry tick labels, and PNG/SVG export.

  • DOS Plotter Suite (.EIG / .PDOS.xml): Calculates Total DOS using the official ‘Util/Eig2DOS‘ algorithm with Gaussian or Lorentzian broadening, decomposes orbital projections (s,p,d,fs, p, d, f), and exports data columns.

  • Simulated STM Topography: Renders constant-height and constant-current STM topography maps based on the Tersoff-Hamann approximation.

  • TIMES Execution Profiler: Upload your SystemLabel.times or TIMES file. Displays total elapsed wall-clock time, cumulative core CPU hours, MPI node count, load balancing ratio (Avg/MaxAvg/Max), top routine bottleneck bar charts, and a searchable, sortable routine table with 1-click clipboard copy!

Section 9⃝ MD / Relaxation: Geometry Optimization & Dynamics

  • Optimizers: Select CG (standard conjugate gradient), Broyden, or FIRE (superior for complex structures far from equilibrium).

  • Tolerances: Set maximum atomic force component (MD.MaxForceTol, e.g. 0.04 eV/Å) and maximum stress component (MD.MaxStressTol, e.g. 1.0 GPa).

  • Cell Relaxation: Toggle MD.VariableCell true to relax cell vectors, or activate Constant.Volume to relax cell shape while keeping total volume fixed.

  • Restarting Relaxations: Check MD.UseSaveCG true to resume conjugate-gradient history from SystemLabel.CG.

  • Molecular Dynamics Ensembles: Toggle Verlet (microcanonical NVENVE), Nose (canonical NVTNVT thermostat), or ParrinelloRahman (isobaric-isothermal NPTNPT). Set time step (MD.LengthTimeStep, e.g. 1.0 fs) and temperatures.

Section 1⃝0 CI-NEB Suite: Transition State Search

  • Climbing Image NEB: Identifies minimum energy pathways (MEP) and saddle-point transition states for chemical reactions, vacancy diffusion, and ion migration.

  • IDPP Interpolation: Upload Initial and Final state CIF or FDF files. The builder uses Image Dependent Pair Potential (IDPP) interpolation to generate NN smooth, unskewed intermediate reaction frames without atom collisions.

  • 3D Reaction Pathway Slider: Scrub through images to inspect the reaction path in 3D.

  • Integrated Pseudopotential Verification: Confirms that all reacting elements have valid pseudopotential files available.

  • 1-Click Download CI-NEB Suite (.zip): Generates all image FDF files (image_00.fdf to image_0N.fdf), automated ASE CI-NEB driver (cineb_siesta_driver.py), barrier plotter (plot_neb_barrier.py), and parallel SLURM runner (run_cineb.sh).

Section 1⃝1 Phonons & Vibrations: Force Constants & Vibra

  • Finite Displacement Method: Calculates harmonic force constants by displacing atoms in small finite steps (MD.TypeOfRun FC).

  • Displacement Amplitude: FC.Displacement (default 0.04 Bohr ≈0.021 Å\approx 0.021\text{ \AA}).

  • Atom Subsets: Select subset of atoms to displace (FC.first and FC.last) to focus on surface adsorbate vibrations while omitting substrate atoms.

  • Polar Materials & LO-TO Splitting: Toggle BornCharge true to compute Born effective charge tensors and macroscopic dielectric matrices.

  • Supercell Builder: Expands the unit cell into a 2×2×22\times2\times2 supercell to account for interatomic force ranges beyond the primary cell.

  • 1-Click Download Phonon Suite (.zip): Generates supercell_fc.fdf, vibra.fdf, plot_phonon_dispersion.py, and run_phonon.sh.

Section 1⃝2 Surface, Work Function & Adsorption Analysis

A dedicated post-DFT surface science laboratory containing 5 specialized tools:

  1. Adsorption Energy (EadsE_{\text{ads}}) Calculator: Input total energy of the complex, clean slab, and isolated molecule to calculate binding strength: Eads=Etotal−Eslab−EmolE_{\text{ads}} = E_{\text{total}} - E_{\text{slab}} - E_{\text{mol}} Categorizes interaction as physical physisorption (|Eads|<0.8 eV|E_{\text{ads}}| < 0.8\text{ eV}) or chemical bonding (|Eads|>1.0 eV|E_{\text{ads}}| > 1.0\text{ eV}).

  2. Planar Average Charge Density Difference (CDD): Upload difference cube or data file. Displays real-space charge redistribution Δρ‾(z)\Delta\bar{\rho}(z), electron accumulation zones (bonding), depletion zones (charge loss), and cumulative charge transfer ΔQ(z)\Delta Q(z) with interface dipole μ\mu in Debye.

  3. Multi-Surface Work Function Comparison Studio: Compare multiple surface states (e.g. clean perovskite vs passivated perovskite). Automatically aligns Fermi levels, extracts asymptotic vacuum plateaus VvacV_{\text{vac}}, computes work functions (Φ=Vvac−EF\Phi = V_{\text{vac}} - E_F), evaluates dipole steps (ΔV\Delta V), and exports vector SVG, 300 DPI PNG, 300 DPI TIFF, or raw column data.

  4. 3D Energy Band Alignment & Heterojunction Diagram: Construct publication-ready band alignment diagrams for solar cells, LEDs, and catalysts. Add custom layers (absorber, ETL, HTL, metal contacts), adjust CBM/VBM levels, toggle curved carrier extraction arrows (e−e^- and h+h^+), and choose 3D perspective shading.

  5. SIESTA Grid Workflow Drawer: Provides verified terminal commands for Util/Macroave (macroave < macroave.in) and Util/Grid (grid2cube SystemLabel.VH).

Section 1⃝3 VASP to FDF Converter (ASE GUI Constraints)

Designed specifically for researchers who set up geometry constraints in ASE GUI and save as VASP POSCAR:

  • Side-by-Side Dual-Pane Interface: Paste or upload a VASP POSCAR or CONTCAR file on the left; view the live generated SIESTA .fdf on the right.

  • ASE GUI Selective Dynamics Parser: Automatically parses Selective dynamics and flags:

    • F F F: Fully fixed in all directions ⟹\implies serialized as atom [1 – 4].

    • T T F: Fixed along zz only ⟹\implies serialized with trailing dot real notation: atom i 0. 0. 1. (allows in-plane xyxy relaxation while preventing out-of-plane buckling).

    • F F T: Fixed in xyxy plane only ⟹\implies serialized as atom i 1. 1. 0..

    • T T T: Completely free to relax.

  • SIESTA Section 7.7 Controls:

    • Syntax selector: atom [1 – 4] (modern bracket notation), atom from 1 to 4, or explicit list atom 1 2 3 4.

    • Cell vector locks: Checkbox for cell-vector C to freeze the vacuum axis during relaxation.

    • Stress tensor locks: Checkboxes for stress XX, YY, ZZ, XY.

    • Element locks: Checkboxes to freeze all atoms of a species by atomic number (e.g. Z 82 for Pb).

  • Direct PP Folder Field: Enter pseudopotential directory path directly in the converter ribbon.

  • Load to Workspace Button: Clicking this transfers the converted crystal coordinates, lattice vectors, chemical species, and pseudopotential paths into Section 2⃝ and the 3D visualizer!

The Live .fdf Preview Pane

  • Real-time bi-directional reflection: Every input field, checkbox, slider, or table edit re-serializes the FDF instantly.

  • Syntax color coding: Comments (# ...) appear in muted gray italic; data block delimiters (%block / %endblock) appear in bold amber; keywords appear in high-contrast text.

  • Line number counter in the header indicates the total length of the generated file.

Step-by-Step Practical Tutorials

Tutorial A: Bulk Silicon Optimization & Band Structure

  1. Click **Templates ▾** in the top toolbar and select **Bulk SCF (single-point)**.

  2. Set SystemLabel to silicon_bulk in Section 1⃝.

  3. In Section 3⃝, click **Scan Folder** to match Si.psf or Si.psml.

  4. In Section 6⃝, click **Auto-Detect Lattice Path** to populate the FCC path: Γ→X→W→L→Γ\Gamma \to X \to W \to L \to \Gamma.

  5. In Section 9⃝, select optimizer CG and set MD.MaxForceTol 0.02 eV/Ang.

  6. Click **Download Package** in the toolbar.

  7. On your cluster, extract the package and submit:

    unzip silicon_bulk.zip && cd silicon_bulk
bash run_siesta.sh

  8. After completion, open Section 8⃝ Tab 2, drag and drop silicon_bulk.bands, and inspect the electronic dispersion curves!

Tutorial B: FAPbI3FAPbI_3 Perovskite Slab with Fixed Substrate

  1. In the top toolbar, click **Import CIF** and select FAPbI3_cubic.cif.

  2. In Section 2⃝, locate the ** Slab & Vacuum Tools** card. Set vacuum thickness to 20.0 Å and click **Add Vacuum**. Click **Center Slab in Cell**.

  3. Open Section 1⃝3 **VASP to FDF Converter** if importing an ASE GUI relaxed geometry, or freeze bottom layers (z<15 Åz < 15\text{ \AA}) via the Section 7.7 constraint controls. Check cell-vector C to ensure the vacuum gap remains constant.

  4. In Section 4⃝, ensure Slab.DipoleCorrection true and DFTD3 true are enabled. Set MeshCutoff 350 Ry.

  5. In Section 6⃝, verify the kk-grid is set to 4×4×14 \times 4 \times 1.

  6. In Section 8⃝, enable SaveElectrostaticPotential true and WriteMDXmol true.

  7. Click **Download .fdf**.

  8. Upon calculation completion, drag and drop FAPbI3_slab.ANI into Section 8⃝ to play the relaxation movie in 3D!

  9. Run grid2cube FAPbI3_slab.VH and upload FAPbI3_slab.cube into Section 1⃝2 to extract the vacuum plateau and calculate the work function: Φ=Vvac−EF\Phi = V_{\text{vac}} - E_F.

Troubleshooting, Edge Cases & Power-User Tips

Comprehensive diagnostic matrix and troubleshooting remedies for SIESTA calculations.
Symptom / Error Physical / Numerical Root Cause Immediate GUI Remedy
SCF does not converge (energy oscillates wildly) Charge sloshing between localized orbitals or metallic surface states Go to Section 5⃝: Lower DM.MixingWeight from 0.25 to 0.05. Increase ElectronicTemperature to 25–50 meV.
Could not find pseudopotential Missing ‘.psf‘/‘.psml‘ file or incorrect path on remote cluster In Section 3⃝, specify the exact cluster folder in Step 1. The builder embeds the full path into %block ChemicalSpeciesLabel.
Vacuum collapsing during relaxation MD.VariableCell true was enabled without locking the cc-axis In Section 1⃝3 or 9⃝, activate cell-vector C in %block Geometry.Constraints so only in-plane a,ba, b relax.
Eggbox ripple in forces Discrete real-space grid spacing is too coarse relative to core states In Section 4⃝, increase MeshCutoff to ≥350 Ry\ge 350\text{ Ry}. In Section 3⃝, enable PAO.SoftDefault true.
Calculation runs out of wall time Long relaxation or molecular dynamics killed mid-step by SLURM In Section 8⃝, set MaxWalltime (e.g. 23.5 hours) and MaxWalltime.Slack 60 s for a clean emergency restart.
Ghost dipole electric field in vacuum Asymmetric slab with polar adsorbate induced periodic image field In Section 4⃝, enable Slab.DipoleCorrection true and set direction to z.

Keyboard Shortcuts and Hidden Productivity Tips

  • Tab-Separated Paste in Atom Table: Highlight any cell in the atomic coordinates grid in Section 2⃝ and press Ctrl+V to paste multi-column data directly from VESTA or text editors.

  • Camera Projection Snapping: In the 3D Crystal Viewer, press the camera projection buttons to jump directly to primary axes (X,Y,ZX, Y, Z).

  • 1-Click Table Copy in TIMES Analyzer: In Section 8⃝ Tab 2, clicking **Copy** on the execution timer table copies formatted routine timings directly to your clipboard for pasting into reports or spreadsheets.

  • Direct Workspace Transfer: In Section 1⃝3 (VASP Converter), clicking **Load to Workspace** converts your POSCAR structure, parses selective dynamics into Section 7.7 constraints, and injects the geometry directly into Section 2⃝ and the 3D viewer without requiring manual file exports!
